Privacy policy

Last updated: 3 October 2026

story-bot is a personal tool used only by its owner to upload videos to the owner's own YouTube channel through the YouTube Data API.

What data it accesses

With the owner's permission (Google OAuth, scope youtube.upload), story-bot uploads videos, titles, descriptions, tags and thumbnails to the owner's YouTube channel. It does not read, collect or store any other Google account data.

Storage and sharing

The OAuth token is stored only on the owner's own computer. No data is sold, shared with third parties, or used for advertising.

Google API Services

story-bot's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
